▶ studymate-case.fig · Requirement set
BEHAVIOR + QUALITY + CONTROL

A clearer StudyMate requirement set

FR-01 · Generate

Create the plan

Generate a seven-day plan from confirmed classes, deadlines, available hours, and priorities.

FR-02 · Correct

Edit before approval

Let the student move, remove, and approve every suggested study session.

FR-03 · Recover

Fail safely

If AI is unavailable, create a rule-based plan or clearly explain that no plan was created.

QR-01 · Validity

Respect constraints

No class overlap, no missing confirmed deadline, and no excess over declared hours.

QR-02 · Performance

Respond quickly

Return a normal seven-day plan within five seconds under the agreed test load.

CR-01 · Privacy

Use data with control

Get consent before import; minimize AI data; support revoke, export, and deletion.

FR = functional requirement · QR = quality requirement · CR = compliance/control requirement.

▶ studymate-case.fig · Acceptance criteria
MAKE FR-01 TESTABLE

Given → When → Then

Story: Generate a realistic weekly plan

As a student, I want a plan based on my confirmed commitments and available hours so that I can prepare before deadlines without creating impossible study sessions.

Given confirmed classes, deadlines, and 10 available hours
When the student requests a seven-day plan
Then no study session overlaps a class
And every confirmed deadline appears in the plan
And total study time does not exceed 10 hours
And the result appears within five seconds

Acceptance criteria describe observable outcomes—not the algorithm, prompt, model, or database.

▶ studymate-case.fig · Privacy by design
DATA IS A DESIGN DECISION

Collect less, explain use, delete safely

Purpose

Why?

Use schedule data only to create and improve the requested plan.

Minimize

What?

Do not send names or unrelated calendar details to the AI.

Control

Who?

Students review, correct, revoke, and delete their planning data.

Retention

How long?

Keep only what is needed; remove tokens and retained plans safely.
