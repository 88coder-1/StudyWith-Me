เทคนิควันสอบ (จาก Review Guide)Exam-day tactics (from the Review Guide)

  • อ่านโจทย์ให้จบ โดยเฉพาะข้อที่มีคำว่า NOT, ไม่ใช่, incorrect, ผิด มีข้อกลับด้านหลายข้อRead the whole question, especially ones with NOT or incorrect. Several items are inverted.
  • ระวังคำผิว ๆ เช่น กริยา see หรือ เห็น ที่หลอกให้ตอบ FR ทั้งที่เป็น NFR ให้ดูเจตนาของประโยคBeware surface words, e.g. the verb "see" luring you to FR when it is an NFR. Read the sentence's intent.
  • ตัวเลือกยาวสุดหรือ all of the above ไม่ใช่คำตอบเสมอไป ข้อสอบชุดนี้ตัดคำใบ้พวกนี้ออกแล้วThe longest option or "all of the above" is not always right. This paper has removed those tells.
  • ข้ออ่านรูป ดูสัญลักษณ์ก่อน ◆ คือ decision, ○ ประกบ ⊃ คือ interface, กล่อง 3 มิติคือ node แล้วค่อยอ่านความหมายFor diagram items, read the symbol first: ◆ is a decision, ○ meeting ⊃ is an interface, a 3-D box is a node. Then read the meaning.
